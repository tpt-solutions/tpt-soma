# tpt-soma-ingest

Ingestion parsers for VCF and AnnData/h5ad with checksum-on-write and quarantine.

Part of the `tpt-soma` multi-scale computational physiology platform.

`tpt-soma-ingest` is where external omics files enter the platform. It parses VCF variant files and AnnData (`.h5ad`) single-cell files, records a checksum when each file is written, and stages uploads in quarantine until they are accepted. The input is untrusted, so every parser returns an error on malformed data rather than guessing.

## Features

- **VCF parsing** (`vcf`): `VcfParser` reads variant calls with `noodles` and produces `VariantRecord` values for the genomics tables.
- **AnnData/h5ad parsing** (`h5ad`): `AnnDataParser` reads an HDF5 AnnData file with `hdf5-reader`, returning an `AnnDataResult` with `ScRNASeqRecord` entries and `ScRNASeqMetadata` for the cell and gene dimensions. Use `n_cells`, `n_genes` and `n_records` to check the shape before loading.
- **HTTP upload endpoints** (`endpoint`): `router()` exposes `POST /ingest/vcf` and `POST /ingest/h5ad` as multipart uploads. Each upload is stored via [`tpt-soma-core`](../tpt-soma-core/README.md)'s object store.
- **Checksum on write**: each stored file goes through `upload_with_checksum`, which checks the MD5 of the bytes against the checksum supplied with the upload.
- **Quarantine**: each upload is parsed before it is stored. A file that fails to parse is written to a quarantine key (`quarantine/vcf/` or `quarantine/h5ad/`) and the request returns an error, so only files that parse are stored under the main key.
- **Errors**: `VcfError`, `H5adError` and `AppError` report which part of the file was rejected.

## Endpoints

| Method and path | Body | Result |
|---|---|---|
| `POST /ingest/vcf` | multipart, one VCF file | Stored and parsed variant records |
| `POST /ingest/h5ad` | multipart, one `.h5ad` file | Stored and parsed single-cell records |

These are mounted by [`tpt-soma-api`](../tpt-soma-api/README.md), where they require the `genomic_raw` write capability.

## Test data

`testdata/` holds small `.h5ad` fixtures (dense and sparse), generated by `scripts/gen_fixtures.py`. `tests/h5ad_fixture_tests.rs` checks the h5ad parser against them. `tests/golden_file_tests.rs` compares parser output to recorded results, and some of its cases are `#[ignore]`d. `tests/integration_tests.rs` is `#[ignore]`d and needs PostgreSQL at `TEST_DATABASE_URL`.

## Crate layout

| Module | Responsibility |
|---|---|
| `vcf` | `VcfParser`, `VariantRecord`, `VcfError` |
| `h5ad` | `AnnDataParser`, `AnnDataResult`, `ScRNASeqRecord`, `ScRNASeqMetadata`, `H5adError` |
| `endpoint` | `router`, the upload handlers, `AppError` |

## Running the tests

```sh
cargo test -p tpt-soma-ingest
```

The coverage floor is 70% (see [coverage targets](../../docs/testing/coverage-targets.md)).
